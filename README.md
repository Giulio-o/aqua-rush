# AQUA RUSH 💦

Un piccolo gioco per browser con una squadra di goccioline viventi: raccogli acqua, supera gli ostacoli e fai rifiorire il giardino.

## Come giocare

- Premi **GIOCA**.
- Trascina il dito a destra e sinistra per guidare le gocce. Sul computer usa il mouse tenendo premuto.
- Attraversa i portali per aumentare la squadra, annaffia i fiori ed evita fango, spugne e sole.
- Completa i cinque livelli e usa l’acqua raccolta per migliorare il villaggio.
- Il pulsante **Ⅱ** mette il gioco in pausa.

I progressi vengono salvati nel browser sul dispositivo utilizzato. Il gioco non contiene pubblicità e non richiede account.

## Avvio

Apri `index.html` in un browser moderno. Non sono necessari installazione o compilazione.

## GitHub Pages

Il sito usa i file statici della cartella principale del branch `main`.
Configurazione prevista: **Settings → Pages → Deploy from a branch → main → / (root)**.

## File

- `index.html`: gioco completo, con grafica, stili e logica incorporati.
- `.nojekyll`: indica a GitHub Pages di pubblicare direttamente i file statici.
- `README.md`: descrizione e istruzioni.
