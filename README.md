# AQUA RUSH 💦

Un gioco per browser con una squadra di goccioline viventi: schiva gli ostacoli, raccogli acqua e spegni gli incendi per far rifiorire il giardino.

**[Gioca ad AQUA RUSH](https://giulio-o.github.io/aqua-rush/)**

## Come giocare

- Premi **GIOCA**.
- Trascina il dito a destra e sinistra per guidare le gocce e mirare. Sul computer usa il mouse tenendo premuto oppure le frecce.
- Lo spruzzo è automatico: punta sulle fiamme per svuotare la loro barra. Tronchi, pozzanghere di fango e spugne vanno schivati.
- Raccogli i portali azzurri per aumentare la squadra. Le capsule **TURBO** raddoppiano la forza e **VENTAGLIO** allarga il getto per dieci secondi.
- Al termine del percorso la squadra si ferma: premi **SPEGNIAMOLO!** e svuota la barra dell’incendio finale per completare il livello.
- Usa l’acqua guadagnata nel villaggio per aumentare la squadra, potenziare la pompa o allargare lo spruzzo. Sono miglioramenti permanenti, con tre livelli ciascuno.
- Il pulsante **Ⅱ** mette il gioco in pausa.

I progressi vengono salvati nel browser sul dispositivo utilizzato. I salvataggi della prima demo sono conservati. Il gioco non contiene pubblicità e non richiede account.

## Le cinque missioni finali

1. Prato Assetato: la quercia delle scintille.
2. Giardino delle Bolle: il carretto fumante.
3. Parco delle Fontane: la torre di fiammelle.
4. Spiaggia Splendente: il grande falò della spiaggia.
5. Festa dell’Arcobaleno: il vulcanetto di brace.

## Avvio

Apri `index.html` in un browser moderno. Non sono necessari installazione o compilazione.

## GitHub Pages

Il sito usa i file statici della cartella principale del branch `main`.
Configurazione: **Settings → Pages → Deploy from a branch → main → / (root)**.

## File

- `index.html`: schermate, comandi e indicatori.
- `game.js`: gioco e grafica vettoriale animata, nitida anche sugli schermi ad alta densità.
- `style.css`: stili e adattamento a schermi piccoli.
- `.nojekyll`: indica a GitHub Pages di pubblicare direttamente i file statici.
- `README.md`: descrizione e istruzioni.
